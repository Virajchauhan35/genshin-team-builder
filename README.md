# Genshin Team Builder

A React app that suggests optimal Genshin Impact team compositions based on your character roster. It matches your characters against known synergy archetypes (National, Freeze, Aggravate, Hyperbloom) and explains why each team works.

🔗 **Live Demo:** [genshin-team-builder-nine.vercel.app](https://genshin-team-builder-nine.vercel.app)

## Features

- Character and archetype matching
- Team selection logic
- Best-team suggestion with an explanation of why each team works

## Tech Stack

- React
- Vite
- Deployed on Vercel

## Run Locally

```bash
git clone https://github.com/Virajchauhan35/genshin-team-builder.git
cd genshin-team-builder
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build for Production

```bash
npm run build
```

The output goes to the `dist` folder.
